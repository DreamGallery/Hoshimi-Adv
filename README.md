# Hoshimi-Adv

《偶像荣耀》（IDOLY PRIDE）的 ADV 剧情文本资源归档，定时更新。

- Resource/ 保存游戏原始的 adv_*.txt。
- CSV/ 保存从有文本内容的 TXT 导出的待翻译 CSV。按剧情类别、角色、活动或章节分类。
- revision 记录当前 Octo 资源版本。

没有可提取文本的 TXT 仍保留在 Resource/，但不生成空 CSV。
